# Скачиваемые файлы

В эту папку кладутся собранные версии лаунчера, на которые ссылается сайт:

- `VOID-Setup-<версия>.exe` — установщик;
- `VOID-Portable-<версия>.exe` — portable-версия.

Сами `.exe` не хранятся в git: они больше лимита GitHub в 100 МБ на файл.
Для публикации сайта используйте GitHub Releases и замените ссылки в
`site/index.html` на адреса релизов, например:

```
https://github.com/<логин>/<репозиторий>/releases/download/v1.2.0/VOID-Setup-1.2.0.exe
```
